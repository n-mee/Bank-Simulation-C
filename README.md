# cBankSim

A recreation of already existing bank — created in C from scratch.

## Description

A Bank Simulation recreated using C.

Before you say anything, ill be the first one to name a few questions:

- `"Why a bank, and why in C?"`: Well, first of this was meant to be more of a transaction management but evovled into a recreation of a bank. And why C? well i wanted to learn C due to its rumors that teaches you solid fundamentals.

- `"Isn't C hard? there is Java or C++ to learn on"`: Well that is technically true, however the sole reason why i chose C despite creating something that doesn't align with the scope of C (which usually OS and other low-level stuff) was because it allows me to learn directly on my mistakes by not holding my hand, sure i can choose the safer route but my learning preference will always be the hardest route.

- `"It's been 4 months and you havent finished this. Why?"`: Well, like [my profile decription](<https://github.com/n-mee>) said: The reason why i haven't finished this was to ensure that i've learned properly, while also dealing with real-life stuff, so technically i only have little time but so far, it seems like i my learning speed still catched up a bit since it will take usually 6 months before i even create a 2nd version of this cBankSim

So far, i will assume that the whole project is maybe around __70%__~ish done, i only have to work on a few things like account management, role privileges and add a few modern bank features — so i can safely call it a bank not an ATM machine.

## Status and Updates

> Current status: __WIP__

Like stated above — it is a recreation of an existing bank which can be seen and use around the world.

So far, the current state of the project is still on the ATM side, there is still not account management and other modern bank website features. So technically this is it its earlier stages which i will call `"The ATM stage"`

However since the inclusion of a `mini-database` which uses a dynamic array as its data-structure and a persistent data-serialization, more security verification checks, as well as more new logic like database handling and menu changes. It can be certain and safe to say that modern bank features will be worked-on sooner.

That will be all for now, if you wanna know what changes have been made feel free to look at the `commits` section to see what and how each code had been altered.
